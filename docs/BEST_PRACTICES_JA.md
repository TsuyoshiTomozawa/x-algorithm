## まず大原則を3つ

### 原則1：Xは「いいね」をほとんど評価していない

タイムラインの表示順は、行動ごとの点数の合計で決まります。その点数表がこれです。

```
リンクをコピーして共有される  ████████████████████ 20.0
リプライされる（相互フォロー） ████████████████████ 20.0
リプライされる（通常）        █████ 5.0
引用される                    █████ 5.0
DMで送られる                  █████ 5.0
フォローされる                ████ 4.0
リポストされる                █ 1.0
いいねされる                  ▌0.5
```

**いいねはリプライの1/10、リンクコピー共有の1/40の重みしかありません。**

> 💡 補足：この点数は「その行動の価値」と「その行動の起こりにくさ」の両方を反映した設定です（コードのコメントに明記）。稀な行動ほど点数が高くなるよう調整されているので、「リプライ1件＝いいね10件」という単純な換算ではありません。ただし **稀で重い行動を引き起こす投稿が勝つ** という結論は変わりません。

### 原則2：マイナス点は桁が違う

```
通報される        ████████████████████████ -234.0
ミュートされる    ██████ -58.8
「興味がない」    ████ -43.2
ブロックされる    ███ -31.2
```

プラスの最大が20点なのに対し、通報は-234点。**1つのネガティブは、大量のポジティブを吹き飛ばします。**

さらに悪いことに、ネガティブは「その投稿が下がる」だけでは終わりません。ブロック率・通報率が高いアカウントには**アカウント単位のラベル**が付き、フォロー外への配信が恒久的に止まります（後述のQ9）。

### 原則3：オリジナル投稿が構造的に有利

同じ内容でも、投稿の「形式」によって最初から点数が変わります。

| 形式 | 扱い |
| --- | --- |
| **オリジナル投稿** | 満点スタート。全ブーストの対象 |
| **引用ツイート** | **オリジナル投稿と同じ扱い**（後述Q2） |
| リプライ投稿 | フォロワー相手でも **×0.75**。ブースト対象外 |
| リポスト | フォロワー相手でも **×0.75**。ブースト対象外 |

## 用語の整理：「リプライ」は2つの意味がある

ここを混同すると、以降の話が正反対に読めてしまいます。

**リプライ = 投稿へのコメント（返信）** のことです。投稿の下にある吹き出しアイコンから書くもの。ただし、**自分がされる側なのか、する側なのか**でスコア上の扱いが真逆になります。

| | 何が起きているか | 扱い |
| --- | --- | --- |
| **リプライ「される」** | 自分の投稿に誰かがコメントする | **+5.0**（相互フォローなら **+20.0**）✅ |
| **リプライ「する」** | 自分が他人の投稿にコメントする | そのコメント自体が「リプライ投稿」として **×0.75** ❌ |

つまり **「リプライは有効」と「リプライ投稿は不利」は矛盾していません。** 立場が違うだけです。

- 自分の投稿にコメントが集まる → 強力なプラス（いいねの10倍相当）
- 自分が書いたコメント → その投稿自体は減点され、ブーストも新人枠も対象外

### 投稿の形式ごとの用語

| 用語 | 何のことか | スコア扱い |
| --- | --- | --- |
| **オリジナル投稿** | 普通に投稿する | ×1.00 ⭐⭐⭐⭐⭐ |
| **引用ツイート** | 他人の投稿を引用して一言添える | ×1.00 ⭐⭐⭐⭐⭐ |
| **リプライ投稿** | 他人の投稿にコメントする | ×0.75 ⭐⭐ |
| **リポスト** | そのまま再投稿（RT） | ×0.75 ⭐ |
| **スレッド2投稿目以降** | 自分の投稿に自分でつなげる | ×0.75 ⭐⭐ |

> ⚠ **スレッドの続きも、技術的には「リプライ」です。** 自分自身へのリプライなので後述の表示制限は受けませんが、×0.75 の減点は受けます。**「スレッドは1投稿目が全て」** という結論はここから来ています。1投稿目が伸びなければ、2投稿目以降は誰にも届きません。

## 全アクション・ポイント早見表

Xの設定ファイルから機械的に抽出した、**現在の本番値の完全な一覧**です。

### まず、点数の仕組み

```
投稿のスコア = すべてのアクションについて（ 点数 × その人がそうする確率 ）を足したもの
```

⚠ **「リプライされたら5点もらえる」ではありません。**

Xは投稿を表示する**前**に、「この人はこの投稿にリプライしそうか？」をAIで予測します。その**予測確率**に点数を掛けます。

```
例：リプライされる確率が 2% と予測された投稿
    → 5.0 × 0.02 = 0.1 がスコアに加算される
```

つまり点数が高い項目は、**「起きたときの価値が高い」＋「めったに起きない」** の両方を意味します。実務上の読み方はシンプルです。

> **点数の高い行動を引き起こす投稿ほど、上位に出やすくなる。**

### 掛け算でかかる補正

上の点数を全部足した**あとに**、掛け算で効いてくる補正です。**こちらのほうが影響が大きい場合があります。**

| 補正 | 倍率 | 対象 |
| --- | --- | --- |
| **フォロー外への配信** | **×0.75** | フォローされていない人に見せるとき |
| **リプライ投稿・リポスト** | **×0.75** | **フォロワーに見せるときも減点されます** |
| トピック経由のフォロー外 | ×0.5 | トピックから来た表示 |
| 新規ユーザー向け | ×0.00001 | ほぼ遮断（現在は実質使われていません） |

### 自分の投稿同士の共食い

同じ人の投稿が並ぶと、**2件目以降**が減点されます。**一番いい投稿は減点されません。**

| 何件目か | 倍率 |
| --- | --- |
| 1件目（自分の中で最高スコア） | ×1.00 |
| **2件目** | **×0.625** |
| 3件目 | ×0.44 |
| 4件目 | ×0.34 |
| 5件目以降 | ×0.25（下限） |

### 順位の強制引き上げ（新人枠）

| 補正 | 内容 |
| --- | --- |
| **新人枠** | 条件を満たす投稿を **15番目あたりまで強制的に引き上げ**。1回の表示につき1件だけ |

条件：フォロワー **1,000人以下** ／ その投稿の表示回数 **1,000回未満** ／ **オリジナル投稿か引用** ／ 24時間以内 ／ 元の順位が下位すぎない

### この表の使い方

**1. いいねを目標にしない**

いいねは最下位クラスの0.5です。**同じ労力なら「保存したくなる情報」を作るほうが40倍効率的**です。

**2. マイナスは桁が違うと理解する**

プラスの最大が20なのに対し、通報は-234。**炎上狙いは、算数として成立しません。**

**3. 掛け算の補正を軽視しない**

「リポストは1.0点もらえる」と考えるより、「リポストすると自分の投稿が×0.75になる」という掛け算のほうが効きます。

**4. 迷ったら「送りたくなるか」で判断する**

最高点の20.0は**リンクをコピーして誰かに送られること**です。「面白い」より「役に立つから共有したい」を狙ってください。

## Q&A：よくある疑問にコードで答える

### Q1. 連投はダメ？何分空ければいい？

#### 🔴 「◯分空けろ」というルールはコードに存在しません

時間ベースのクールダウンは実装されていません。代わりにあるのは **「同じ人の投稿が複数並んだら、2件目以降を減点する」** という仕組みです。

```
1件目（あなたの投稿の中で一番スコアが高いもの）  ×1.00
2件目                                            ×0.625
3件目                                            ×0.44
4件目                                            ×0.34
5件目以降                                        ×0.25（下限）
```

#### 🟡 重要：連投そのものが罰されるわけではない

減点は**スコア順**に適用されます。つまり：

- あなたの**一番いい投稿は減点されません**（必ず×1.00）
- 減点されるのは**2番手以降の投稿**

なので「連投するとアカウント全体が沈む」のではなく、**「自分の投稿同士で共食いして、2番手以降が埋もれる」** が正確です。

#### 🟡 では実際、何を基準に空ければいいのか

この減点は「**同じ人が同時に候補に並んだとき**」に発動します。そして、**フォロワーが既に見た投稿は候補から除外されます**（コードで確認済み）。

つまり本当の分かれ目は時間ではなく、これです：

> **前の投稿を、フォロワーがもう見たかどうか**

- フォロワーがXを開いて前の投稿を見た → 前の投稿は候補から消える → 次の投稿は満点で勝負できる
- フォロワーがまだ開いていない → 前の投稿と新しい投稿が並ぶ → 2件目が0.625倍

#### ✅ 実務的な結論

| 間隔 | 結果 |
| --- | --- |
| **10分以内の連投** | ほぼ確実に全部が同じ候補に並ぶ。**最悪** |
| **1時間** | 多くのフォロワーはまだ見ていない。共食いが起きやすい |
| **2〜4時間** | 現実的な最低ライン。多くのフォロワーが1回はXを開く |
| **半日** | ほぼ確実に共食いしない |

**目安：1日3〜5投稿、2〜4時間以上空ける。** ただし「分」の単位で厳密に管理する意味はありません。**フォロワーの生活リズム（朝・昼休み・帰宅後・夜）に合わせて散らす**のが本質です。

> ⚠ 注意：この共食いは、あなたの投稿が48時間以内なら起こり続けます。「昨日の投稿」もまだ候補に残っているので、実際には毎日の投稿数そのものを抑える意味があります。

### Q2. 引用ツイートは有効？

#### 🟢 有効です。しかもリポストより圧倒的に有利です

これはコードを読んで分かった、最も実用価値の高い発見です。

アルゴリズムが「減点対象」を判定するとき、コードはこう書かれています：

```
減点しない条件 = リプライ投稿ではない かつ リポストではない
```

**引用ツイートはどちらにも該当しません。** つまりコード上、引用ツイートは **完全にオリジナル投稿として扱われます。**

| | リポスト | 引用ツイート |
| --- | --- | --- |
| フォロワーへの配信 | **×0.75 減点** | **減点なし** |
| 相互フォローブースト（4倍） | ❌ 対象外 | ✅ **対象** |
| 新人枠（フォロワー1000人未満の救済） | ❌ 対象外 | ✅ **対象** |
| 引用されたときの点数 | — | **5.0**（いいねの10倍相当） |

#### ✅ 結論

> **「リポストしたい」と思ったら、代わりに一言添えて引用ツイートする。** これだけでコード上の扱いが別物になります。

#### ⚠ ただし1つ重大な落とし穴があります

🟢 **引用元の投稿が非表示判定を受けていると、あなたの引用ツイートも道連れで消えます。**

コード上、引用元・リポスト元・スレッドの親投稿のいずれかが「非表示」と判定されると、それを引用したあなたの投稿も除外されます。

つまり：

- スパム判定されているアカウントを引用 → **あなたの投稿ごと消える**
- 凍結されたアカウントの投稿を引用 → **同じく消える**
- 炎上して通報が集まっているアカウントを引用 → **同じく消える**

**「叩くために引用する」のが最悪の手**である理由がこれです。批判のつもりで問題アカウントを引用すると、自分の投稿ごと配信されなくなります。

### Q3. 記事・長文は有効？

#### 🔴 「記事」に固有の優遇はコードにありません

X の記事機能（Articles）に対する専用のスコア加点は、ランキングのコードには存在しませんでした。記事IDは配信履歴の記録に使われているだけです。

#### 🟡 ただし長文が有利になる「間接的な経路」はあります

点数表に、こういう項目があります：

```
滞在秒数（読まれた時間）      +0.004 / 秒
素通りされた（読まれなかった） -0.02
```

一見小さいですが、**「読まれずにスクロールされる」ことにマイナス点がある**のがポイントです。

- 短い投稿 → 一瞬で判断されて素通りされやすい
- 長文・スレッド・画像付き → 目が止まり、滞在が伸びる

#### ✅ 結論

**「記事だから有利」ではなく「読ませられるから有利」。** 形式（記事機能を使うか、普通の投稿か、スレッドか）は本質ではありません。重要なのは：

1. 冒頭1行でスクロールを止める（＝素通りの-0.02を避ける）
2. 最後まで読ませる（＝滞在時間の加点）
3. 読み終わったあと「誰かに送りたい」と思わせる（＝最高得点20.0）

### Q4. リンクを貼ると伸びない？

#### 🔴 通説はコード上、否定されます

「外部リンクを貼るとアルゴリズムに嫌われる」とよく言われますが、コードには**リンク付き投稿へのペナルティは存在しません**。

むしろ逆で、**「リンクを開く」には +0.2 のプラス点** が付いています。

#### ⚠ ただし条件が2つあります

1. 🟢 **悪質URLは即除外**：`MALICIOUS_URL_DROP` というルールがあり、危険なリンクを含む投稿はフォロー外への配信から完全に除外されます。短縮URLや怪しいドメインは避けてください。

2. 🟡 **「釣りリンク」対策の仕組みが実装済み（現在は未稼働）**：「クリックはされるが、いいねはされない」投稿を減点する機構がコードに用意されています。今はオフですが、いつオンになってもおかしくありません。**クリックを稼ぐだけで中身がないリンク投稿は、将来的にリスクがあります。**

#### ✅ 結論

**リンクは貼っていい。ただしリンク先が本当に良質であること。**

### Q5. 動画は優遇される？

#### 🔴 コード上、動画は特別扱いされていません

| 項目 | 点数 |
| --- | --- |
| 動画を開く | 0.05 |
| 動画を最後まで見る | 0.05 |

いいね（0.5）の1/10です。しかも動画完視聴のボーナスには条件があります：

- 🟢 **10秒より長い動画**でないと加点されない
- 🟢 **見る人のフォロワーが1万人未満**の場合のみ加点（インフルエンサーが見ても加点されない）

#### ✅ 結論

**「動画を出せばアルゴリズムに優遇される」はコード上、根拠がありません。**

動画が伸びるとすれば、それは動画そのものへの加点ではなく、**動画が滞在時間を伸ばし、共有されやすいから**です。同じことがテキストや画像でできるなら、動画である必要はありません。

### Q6. いいねを稼げばいい？

#### 🟢 いいねは最も割の悪い指標です

いいね 0.5 に対して：

- **リンクコピー共有 20.0（40倍）**
- リプライ 5.0（10倍）
- 引用 5.0（10倍）
- DM共有 5.0（10倍）
- フォロー 4.0（8倍）

#### 🟡 さらに、いいねには「もう1つの役割」があります

アカウントの健全性を判定する仕組み（agatha）は、こういう比率を見ています：

```
ブロック数 ÷ いいね数
通報数   ÷ いいね数
```

**いいねは「分母」として使われています。** つまり、いいねを集めることは「点数を稼ぐため」ではなく、**「ブロック・通報の比率を薄めて、アカウントラベルが付くのを防ぐため」** に効いています。

#### ✅ 結論

**狙うべきは「いいね」ではなく「保存・DM転送・引用・リプライ」。**

具体的には「面白い」より **「役に立つから誰かに送りたい」「後で見返したい」** を狙う。まとめ、手順、図解、リスト、比較表などが構造的に強いです。

### Q7. リプ周り・相互フォローは効果ある？

結論から言うと、**両方とも「効くが、多くの人が期待している方向には効かない」** です。順番に見ていきます。

#### 🔴 まず：リプ周りに「露出効果」はありません

「大きいアカウントにリプライすると、そのフォロワーに見てもらえる」という通説がありますが、**For Youタイムラインに関してはコード上、成立しません。**

リプライ投稿には**2つのフィルタ**が順にかかります。

```
① OONRetweetReplyFilter
   → あなたをフォローしていない人には、あなたのリプライは表示されない

② SelfReplyChainFilter
   → さらに「リプライした相手」もフォローしていない人には表示されない
```

両方を合わせた結果、あなたのリプライがFor Youに出る条件はこうなります。

> **「あなた」と「リプライした相手」の両方をフォローしている人にしか表示されない**

相手のフォロワーであっても、**あなたをフォローしていなければFor Youには一切出ません**。「有名人にリプして自分を知ってもらう」という導線は、For You経由では機能しません。

> 💡 ただし、投稿の会話画面（返信一覧）を直接開いた人には見えます。これはアルゴリズムの外側の話なので、このリポジトリの範囲外です。リプ周りの露出効果があるとすれば、そちら経由です。

#### 🟢 では何が効くのか：相互フォローを作ること

コードで最大のブーストがこれです。

> **相互フォロー相手のオリジナル投稿は、リプライ点数が 5.0 → 20.0（4倍）になる**

つまりリプ周りの本当の価値は、**「その投稿が伸びること」ではなく「相手と関係ができて、相互フォローになること」** にあります。一度相互になれば、あなたの**今後のすべての投稿**の配信力が上がります。

#### ⚠ ただし、相互フォローも「数」では意味がありません

ここが最も誤解されやすい点です。スコアの計算式を思い出してください。

```
スコア寄与 = 重み × その人がリプライする確率
           = 20.0 × P(リプライ)
```

**ブーストが上げるのは「重み」の側だけです。** 確率の側は、その閲覧者の実際の行動履歴からAIが予測します。

リプライを一度もくれない相互フォロー相手の場合：

```
20.0 × ほぼ0 = ほぼ0
```

**何も起きません。** ブーストは「もともとある関係を増幅する」だけで、**関係そのものは作りません**。

`#相互フォロー` のようなフォロー返し稼ぎで数を積んでも、スコアは動かないということです。効くのは **実際にリプライが往復する関係** だけです。

#### ⚠ さらに：相互フォローは「新規リーチ」を1ミリも増やしません

ブーストの判定は、こういう順序で行われます。

```
① 候補の投稿のうち、著者が「自分がフォローしている人」のものを抽出
② その著者たちが自分をフォローし返しているかを確認
③ 両方成立したものだけブースト対象
```

定義上、**対象はすでにあなたをフォローしている人だけ**です。

| | 相互フォロー |
| --- | --- |
| 既存フォロワーのTLでの表示率 | ⬆️ 上がる |
| **フォロー外への新規リーチ** | **変わらない** |

新規リーチを増やしたいなら、効くのは別の仕組みです ―― **新人枠**（Q8）、**引用ツイート**（Q2）、そして**フォロー外に届く投稿の質**。相互フォローとは完全に別系統です。

#### 🔴 機械的なリプ周り・相互フォロー稼ぎは逆効果

コードには以下の仕組みがあり、数を稼ぐ運用にはリスクがあります。

| 仕組み | 何が起きるか |
| --- | --- |
| **協調的スパム検出**（`CoordinatedSpamScorer`） | 複数アカウントによる定型的なリプライのパターンを、AIがスレッド全体を読んで判定。「おはようございます！」を1日100件のような運用はスパム判定のリスク |
| **user-cred-v2**（PageRank） | 信用スコアは**有力アカウントから流れてくる**仕組み。低品質アカウント同士の相互フォロークラスタからはほぼ流入せず、**数を積んでもスコアはほぼ上がりません** |
| **bdsm** | 行動シーケンスから非真正な挙動を検出。大量フォロー・解除の反復パターンは検出対象 |
| **自分のTLの劣化** | AIの主入力は**あなた自身の行動履歴**。興味のないアカウントを大量フォローすると自分のおすすめ品質が落ちます |

#### ✅ 結論

> **「相互フォローの数」ではなく「実際にリプライが往復する相手の数」を増やす。**

- ✅ 同ジャンルで実際に会話が成立する相手と相互になる（**10人でも十分機能します**）
- ✅ 相手の投稿に実際にリプライする（相手のTLでの自分の表示率も上がる）
- ❌ フォロー返し目的の無差別フォロー（信用スコア的にほぼ無価値、検出リスクあり）
- ❌ 露出目的のリプ周り（For You経由の露出はゼロ）
- ❌ 新規リーチ目的で相互フォローを増やす（**そもそも経路が違います**）

### Q8. フォロワーが少ないうちは不利？

#### 🟢 コードには明示的な「新人枠」があります

以下を**すべて**満たす投稿は、1回のタイムライン表示につき1件だけ、**強制的に15番目あたりまで順位が引き上げられます**。

| 条件 | 基準 |
| --- | --- |
| 著者のフォロワー数 | **1,000人以下** |
| その投稿の表示回数 | **1,000回未満** |
| 投稿の種類 | **オリジナル投稿または引用**（リプライ・リポストは対象外） |
| 投稿の新しさ | 24時間以内 |
| 元の順位 | ある程度以上のスコアが必要（下位15%は対象外） |

#### ✅ 結論

**フォロワー1,000人未満は、コード上むしろ優遇されています。**

ただし条件が厳しく、**リプライとリポストは完全に対象外**。この段階では**オリジナル投稿と引用ツイートに集中すべき**です。

> 💡 実際、この新人枠と `1fav` インデックス（Q11）の組み合わせで、**フォロワー335人・いいね16のアカウントが1投稿で15,000インプレッションに到達した実例**があります（[診断手順の実例](#実例配信は足りているのにコンテンツが詰まっていたケース)を参照）。**小規模アカウントでも配信の仕組みは十分に働きます。**

「フォロワーが少ないから伸びない」のではなく、**「リプライとリポストばかりしていて、救済枠の条件を満たしていない」** ケースが多いはずです。

### Q9. 「シャドウバン」は本当にある？

#### 🟢 あります。コードに明確な形で実装されています

ただし、一般に想像されている「アカウントを非表示にする」ものとは仕組みが違います。

**表示ルールが2段構えになっています。**

```
【第1段】全員に適用されるルール
  → 凍結アカウント、法的削除、明確なスパム、暴力的発言 など
  → ここで引っかかると、フォロワーにも表示されない

【第2段】フォロー外の人におすすめするときだけ、追加で適用されるルール
  → ここで引っかかると…
     フォロワーには普通に表示される
     でも、フォロー外の人には一切おすすめされない
```

**第2段で除外される条件（一部）：**

- スパム判定（高再現率＝疑わしきは除外する厳しめの判定）
- 「増幅しない」ラベル
- 悪質URL
- 成人向け・グロ判定
- なりすまし判定
- 乗っ取られアカウント判定
- 攻撃的判定（高再現率）
- **アイコン画像が成人向け判定**
- **ヘッダー画像が成人向け判定**

#### 🟡 これが「投稿は見えているのに伸びない」の正体

自分のフォロワーからは普通に見えるので、**本人は気づきにくい**。しかしフォロー外への配信が完全に止まっているので、新規リーチがゼロになります。

#### ✅ 対処法：まず確認する

Xは **[Under the Hood](https://x.com/i/under_the_hood)** という公式ツールを提供しています。**自分のアカウントと投稿に付いているラベルを確認できます。**

> **リーチが伸びないと感じたら、投稿内容を変える前に、まずここを見てください。** ラベルが付いているなら、何を投稿しても無駄です。原因の切り分けが先です。

#### 🟢 ラベルが付く仕組み

アカウント単位の判定は、この比率で行われます：

```
ブロック数 ÷ フォロー外からのいいね数
通報数   ÷ フォロー外からのいいね数   （通報は過去180日分を集計）
```

**「インプレッションは稼いだが、いいねはされず、ブロックと通報だけ増えた」投稿を繰り返すと、ラベルが付きます。**

釣り・煽り・過激な言い回しでバズを取る運用は、短期のインプレッションと引き換えに、**長期のフォロー外リーチを恒久的に失う**構造になっています。しかも通報は180日間カウントされ続けます。

### Q10. 投稿の寿命はどれくらい？

#### 🟢 48時間ちょうどです

コードに `MAX_POST_AGE = 48 * 60 * 60`（48時間）と書かれており、**投稿から48時間経つと、For Youの候補から完全に消えます。**

#### ✅ 結論

- **ストック型の資産にはなりません。** 過去の名投稿がずっと配信され続けることはありません
- 逆に言えば、**失敗した投稿も48時間で消えます**
- **継続的に投稿し続けることが前提の設計**です
- 「48時間以内」なので、**投稿直後の反応が全てではありません**。翌日伸びることもあります

### Q11. フォロー外にはどうやって届くの？

#### 🟢 「いいね数」で登録先が変わる階層構造になっています

フォロー外の人に届くには、まず**取得インデックス**という検索用の棚に登録される必要があります。この棚が、いいね数によって分かれていました。

```
投稿した瞬間     → post_creation の棚
いいね 1 個以上  → 1fav の棚          ← ここから本格的にフォロー外へ
いいね 32 個以上 → 32fav の棚         ← 競争相手が激減する上位の棚
```

#### 🟢 そもそも棚に置いてもらえない投稿があります

```
リプライ         → 登録されない
リポスト         → 登録されない
コミュニティ投稿 → 登録されない
非表示ラベル付き → 登録されない
成人向け判定     → 登録されない
```

**リプライとリポストは、フォロー外の候補にすら入りません。** 配信の段階でも除外されますが、その手前の**棚に置く段階で既に弾かれています**。二重に締め出されている形です。

#### 🟢 いいねが入るたびに棚が更新されます

いいねが付くたびに再登録のイベントが走ります。ただし制限があります。

| 制限 | 値 |
| --- | --- |
| 更新の最短間隔 | 1分 |
| 更新が続く期間 | 最初の更新から48時間 |
| 投稿の上限年齢 | 49時間 |

**投稿直後のいいねほど価値が高い**のはこのためです。48時間の窓を過ぎると、どれだけ反応が付いても棚は更新されません。

#### ✅ 結論

> **オリジナル投稿か引用ツイートを出し、最初の数時間でいいねを集める。** これがフォロー外に出るための唯一の入口です。
>
> 特に **「1投稿で32いいね」** は棚が1段上がる明確な境界線なので、**いいねを複数の投稿に分散させず、1本に集中させる**ほうが有利です。

### Q12. 課金（X Premium）すると伸びる？

#### 🔴 タイムラインの順位に、課金による加点はありません

`home-mixer/scorers/` と `home-mixer/params/param.rs` を検索した結果、**`premium` / `verified` / `subscription` に関する重みは1つも存在しませんでした。**

スコアに使われる26項目（いいね、リプライ、引用、共有、フォロー、滞在時間…）を全部確認しても、課金関連の項目はゼロです。

```
最終スコア = Σ ( 重みᵢ × P(アクションᵢ) )
             ↑ この中に課金の項目は存在しない
```

`subscription_level` がコード内で使われているのは3箇所だけで、**すべて記録用**でした。

| 場所 | 用途 |
| --- | --- |
| `feed_log.rs` | ログ出力 |
| `response_stats_side_effect.rs` | 統計の分類タグ |
| `ads_injection_logging_side_effect.rs` | 広告挿入のログ |

> 💡 `SubscriptionHydrator` と `IneligibleSubscriptionFilter` という似た名前のコードがありますが、これは**クリエイターの有料購読者限定投稿**の処理で、X Premium とは別機能です。

#### 🟢 ただし「信用スコア」には直接効いています

`user-cred-v2` は、フォローグラフ上で PageRank を回してアカウントの信用度を算出する仕組みです。その**初期質量の配り先**がこうなっていました。

```scala
// UserCredV2App.scala
validUserInfoPipe.filter(u => !u.isNearZero && u.isPremium).map(u => UserMass(u.id, 1.0))
```

**初期質量 1.0 を受け取れるのは Premium アカウントだけです。**

```scala
def isPremium: Boolean =
  isBlueVerified || isGrayVerified || isGoldVerified || isVerifiedOrg || isVOAffiliate
```

（青・グレー・ゴールドの認証バッジ、認証済み組織、その関連アカウント）

配分は `(1 - beta) × Premiumに均等 + beta × エンゲージメント加重` で、`beta = 0.5`。つまり**事前分布の半分が Premium アカウントだけに配られています。** 非Premiumは、リンク構造とエンゲージメント経由でしか質量を受け取れません。

#### 🟢 でも、その信用スコアは順位に使われません

パッケージ名を見ると用途が分かります。

```
com.twitter.health.platform_manipulation.user_cred_v2
```

**health（健全性）/ platform_manipulation（プラットフォーム操作対策）** です。このスコアは可視性フィルタが読むラベル判定に使われるもので、ランキングの入力ではありません。

#### ✅ 結論

```
Premium は「順位を上げる」のではなく
          「スパム・不正判定されにくくする」方向に効く
```

| 通説 | 判定 |
| --- | --- |
| 「課金するとタイムラインで優遇される」 | 🔴 **コード上、根拠なし** |
| 「課金すると信用スコアの起点になる」 | 🟢 **事実。PageRankのシード集合そのもの** |

🟡 **推論**：非Premiumの小規模アカウントは質量が溜まりにくく、信用スコアが低く出やすいと考えられます。スパム判定の閾値に近づきやすいという意味で不利になり得ますが、**閾値そのものはコードに書かれていないため、影響の大きさは分かりません。**

> **Premiumの価値は攻めではなく守りです。** 「伸ばす」ためではなく「誤って落とされにくくする」ために効きます。**課金してもリーチが伸びない場合、原因は課金の有無ではなくコンテンツ側にあります。**

## リーチが伸びないときの診断手順

「伸びない」には**まったく違う原因**が複数あり、対処法も正反対です。**闇雲に投稿を変える前に、必ず切り分けてください。**

### ファネルの4段階

リーチは4段階の掛け算です。どこで詰まっているかを特定します。

```
① 配信      … 何人に表示されたか（インプレッション）
     ↓
② 反応      … いいね・リプライ・リポストが付いたか
     ↓
③ 興味      … プロフィールを見に行かれたか
     ↓
④ 転換      … フォローされたか
```

### 手順1：①が壊れているかを判定する

**基準は「インプレッションがフォロワー数を明確に超えたことがあるか」です。**

| 状態 | 判定 |
| --- | --- |
| フォロワー数の2倍以上を出した投稿がある | 🟢 **配信は正常。**アカウントラベルは否定できます |
| 一度もフォロワー数を超えていない | 🟡 フォロー外が開いていない。手順2へ |

> ⚠ インプレッションがフォロワー数**未満**の数字は、すべてフォロワーだけで説明がつきます。**フォロー外に出た証拠にはなりません。**

アナリティクスの**日別インプレッション**を3ヶ月表示にして、突出した日がないか探すのが最も早い方法です。

### 手順2：ラベルの有無を確認する

[Under the Hood](https://x.com/i/under_the_hood) で確認します（パイロット版のため未対応の場合あり）。

見られない場合の代替判定：

| テスト | 分かること |
| --- | --- |
| ログアウトでプロフィールを見る | 凍結・投稿単位の強い削除ラベルの有無 |
| 別アカウントで自分のリプライを見る | 「さらに返信を表示」に隠れていないか |
| アイコン・ヘッダー画像 | `NsfwAvatarImage` / `NsfwBannerImage` は画像だけで発火。**疑わしければ即差し替え（無料でできる対処）** |

> ⚠ アカウントラベルの効果は**「フォロワー以外へのおすすめから除外」だけ**です。プロフィールもフォロワーのTLも正常に見えるので、**ログアウトテストではアカウントラベルを否定できません**。

### 手順3：②〜④のどこで詰まっているかを特定する

①が正常なら、原因はコンテンツ側です。以下を計算してください。

```
いいね率       = いいね ÷ インプレッション
プロフィール率 = プロフィールアクセス ÷ インプレッション
フォロー率     = フォロー増 ÷ プロフィールアクセス
```

| 詰まっている場所 | 症状 | 原因 |
| --- | --- | --- |
| **②反応** | インプは出るが、いいね率が極端に低い | 見出しと中身のミスマッチ。保存する理由がない |
| **③興味** | 反応はあるが、プロフィールに飛ばれない | **発信者が何者か伝わっていない** |
| **④転換** | プロフィールには来るがフォローされない | プロフィール文・固定投稿・直近の投稿の一貫性 |

---

### 実例：配信は足りているのにコンテンツが詰まっていたケース

実際の診断例です（アカウントが特定されないよう匿名化しています）。

**前提**

| 項目 | 数値 |
| --- | --- |
| フォロワー | 335 |
| 通常のインプレッション | 80〜137 |
| 「シャドウバンでは」という自己申告 | あり |

**手順1の結果**

3ヶ月の日別グラフに、**1日 15,000 インプレッション**の突出した日が存在。

> フォロワー335人に対して15,000。**この時点でアカウントラベルは完全に否定されました。** ラベルの効果は「フォロワー以外への配信停止」なので、15,000は物理的に到達不可能です。

**手順3の結果**

問題の15,000インプ投稿を分解：

| 指標 | 数値 | 率 |
| --- | --- | --- |
| インプレッション | 15,000 | — |
| いいね | 16 | **0.11%** |
| リポスト | 4 | 0.027% |
| **リプライ** | **0** | **0%** |
| プロフィールアクセス | 4 | **0.027%** |
| フォロー増 | 2 | — |

**診断：②反応 と ③興味 で詰まっていた**

プロフィールに来た人の約50%はフォローしており、**④転換は正常**でした。問題はその手前です。

**原因（投稿を読んで特定）**

| 問題 | 内容 |
| --- | --- |
| **見出しと中身のミスマッチ** | 見出しはAI技術の検証を予告していたが、添付画像は投稿者の個人的な手書き日記だった。開いた人の期待と中身が乖離 |
| **保存する理由がない** | 「凄い」という感想のみ。手順・設定・比較・限界などの再現可能な情報がゼロ → 最高得点の「リンクコピー共有 20.0」を1件も獲得できない |
| **リプライする理由がない** | 断定で終わっており、返す言葉がない → 重み5.0が**0件** |
| **発信者が何者か伝わらない** | 専門性を示す文脈が1行もなく、「この人を知りたい」と思われなかった → プロフィール率0.027% |

**結論**

> **配信システムは過剰なほど正常に機能していた。** いいね16（32未満）にもかかわらず15,000まで届いており、`1fav` インデックスと新人枠が想定通り働いていた。
>
> **必要だったのは、投稿数でもフォロワー数でも相互フォローでもなく、運ばれた先で読者に「保存したい」「返信したい」「この人は誰だ」と思わせることだけだった。**

**この診断から得られる一般則**

1. **「シャドウバンされている」と感じたら、まず日別インプレッションの最大値を見る。** 突出した日が1日でもあれば、原因はコンテンツ側で確定します
2. **インプレッションが多いのに反応がないのは、成功ではなく失敗のシグナル。** 配信を無駄遣いした状態です
3. **プロフィール率が0.1%を切るなら、投稿に「自分が何者か」が欠けている**

## 投稿タイプ別・有利不利の早見表

| 投稿の形式 | 基本点 | 相互ブースト | 新人枠 | 誰に表示されるか | 総合 |
| --- | --- | --- | --- | --- | --- |
| **オリジナル投稿** | ×1.00 | ✅ 4倍 | ✅ 対象 | **全員（フォロー外にも）** | ⭐⭐⭐⭐⭐ |
| **引用ツイート** | ×1.00 | ✅ 4倍 | ✅ 対象 | **全員（フォロー外にも）** | ⭐⭐⭐⭐⭐ |
| **スレッド（1投稿目）** | ×1.00 | ✅ 4倍 | ✅ 対象 | **全員（フォロー外にも）** | ⭐⭐⭐⭐⭐ |
| スレッド（2投稿目以降） | ×0.75 | ❌ | ❌ | フォロワーのみ | ⭐⭐ |
| リプライ投稿 | ×0.75 | ❌ | ❌ | **自分と相手の両方をフォローしている人だけ** | ⭐⭐ |
| リポスト | ×0.75 | ❌ | ❌ | フォロワーのみ | ⭐ |

**この表で一番重要なのは右から2列目です。** 新規リーチ（フォロー外への配信）が発生するのは、**オリジナル投稿と引用ツイートだけ**です。リプライ・リポストをいくら重ねても、新しい人には届きません。

> 💡 スレッドの2投稿目以降はリプライ扱いになるため減点されます。**スレッドは「1投稿目単体で価値が完結し、続きが読みたくなる」構成にするのが正解**です。1投稿目が伸びなければ、2投稿目以降は誰にも届きません。

## 1日の運用モデル

コードから導ける、無理のない運用の型です。

```
朝（通勤時間帯）    オリジナル投稿 ①  ← その日の本命。一番いいネタをここに
昼（昼休み）        引用ツイート     ← 話題への自分の視点。リポストの代わりに
夕方（帰宅時間帯）  オリジナル投稿 ②
夜（ゴールデン）    オリジナル投稿 ③  ← 保存・共有されるタイプ（まとめ・手順・図解）

随時                リプ周り少数     ← 相互フォローを作る目的のみ。露出は期待しない
```

### この型の根拠

| 要素 | 根拠 |
| --- | --- |
| 1日3〜4投稿 | 5件目以降は自分の投稿と共食いして×0.25まで落ちる |
| 2〜4時間空ける | フォロワーが前の投稿を見終わる時間を確保するため |
| **新規リーチはオリジナル＋引用だけで作る** | リプライ・リポストはフォロー外に一切届かない |
| リポストではなく引用 | 引用はオリジナル扱い、リポストは×0.75 |
| リプ周りは少数・非定型 | 露出効果はゼロ。目的は関係作りのみ。定型文は協調スパム検出のリスク |
| 夜に保存系コンテンツ | 最高得点20.0の「リンクコピー共有」を狙う |

> ⚠ **「1日30投稿してるのに伸びない」の典型パターン**は、その大半がリプライとリポストで、フォロー外に届く投稿（オリジナル・引用）が1〜2件しかないケースです。**投稿数ではなく、オリジナル投稿と引用ツイートの本数を数えてください。**

## 絶対にやってはいけないこと

| やってはいけないこと | 何が起きるか |
| --- | --- |
| **通報される内容を投稿する** | -234点。プラス最大20点の11倍のマイナス |
| **釣り・煽りでインプレッションを稼ぐ** | ブロック率が上がる → アカウントラベル → **フォロー外配信が恒久停止** |
| **定型リプライの大量投下・相互いいね互助会** | AIが協調スパムとして検出 → スパムラベル |
| **問題アカウントを引用して批判する** | 引用元が非表示判定なら、**あなたの投稿ごと消える** |
| **10分以内の連投** | 2件目0.625倍、3件目0.44倍、4件目0.34倍で共食い |
| **リポスト・リプライ中心の運用** | ×0.75 ＋ ブースト対象外 ＋ 新人枠対象外に加え、**フォロー外に一切届かない** |
| **露出目的で有名人にリプする** | 相手のフォロワーには表示されない。For You経由の効果はゼロ |
| **フォロー返し目的の無差別フォロー** | 信用スコア（PageRank）はほぼ上がらず、非真正な挙動として検出されるリスク |
| **アイコン・ヘッダーにきわどい画像** | それだけでフォロー外配信から完全除外 |
| **短縮URL・怪しい外部リンク** | 悪質URL判定で除外 |

## 投稿前チェックリスト

投稿する前に、この5つを確認してください。

- [ ] **これはオリジナル投稿か引用ツイートか？**（リプライ・リポストはフォロー外に届きません）
- [ ] **冒頭1行でスクロールが止まるか？**（素通りは-0.02、滞在は加点）
- [ ] **見出しで期待させた内容が、中身にちゃんとあるか？**（ミスマッチは反応をゼロにします）
- [ ] **読んだ人が「誰かに送りたい」と思うか？**（DM共有5.0、リンクコピー20.0）
- [ ] **読んだ人に返す言葉があるか？**（断定で終わると、重み5.0のリプライが0件になります）
- [ ] **自分が何者かが1行でも伝わるか？**（フォロー4.0。ここが抜けるとプロフィールに飛ばれません）
- [ ] **前の投稿から2時間以上経っているか？**（共食い回避）
- [ ] **誰かを不快にさせて通報・ブロックされる要素はないか？**（-234点／アカウントラベル）

> **「誰かに送りたい」と思わせるオリジナル投稿と引用ツイートを、2〜4時間空けて1日3〜4件出す。リポストの代わりに引用を使う。リプ周りは露出ではなく、実際に会話が往復する相互フォローを作るためにだけ使う。そして誰も不快にさせない。**
